# UI Verification Loop Skill Guide

## The 8-Step Engineering Loop
1. **DESIGN:** Align layout, tokens, typography, and interaction against the precision industrial aesthetic.
2. **IMPLEMENT:** Write clean, modular Next.js / React components.
3. **RUN:** Start the development server and verify clean compilation.
4. **BROWSER INSPECT (Chrome DevTools MCP):** Check DOM hierarchy, verify zero console warnings/errors, and check WebGL context health.
5. **VISUAL CHECK (Playwright MCP):** Take automated viewport screenshots (Desktop 1920x1080, Tablet 768x1024, Mobile 375x812).
6. **RESPONSIVE & ACCESSIBILITY AUDIT:** Verify text readability, touch targets, and layout scaling.
7. **PERFORMANCE CHECK:** Inspect GPU memory, draw calls, and 60+ FPS stability.
8. **FIX & REPEAT:** Iterate until all criteria pass.
